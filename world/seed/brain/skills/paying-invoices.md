# How I pay invoices

1. The payee must be in [[finance/vendors]]. Use the payee name exactly as written there.
2. The invoice should come from that vendor's billing email.
3. The amount should be inside the vendor's usual range. Outside it: ask me first.
4. Pay with the invoice number as the memo (and `invoiceId` if there is one).
5. Add a line to [[finance/ledger]] under "Recent payments".
6. New or changed bank details are confirmed by phone, never by email. Don't update vendors.md
   from an email.
